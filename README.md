# TFG_PIPELINE2

Proyecto de procesamiento y análisis de señal/videodetección para el Trabajo Fin de Grado.

## Estructura
- `config.py`: configuración del pipeline.
- `main.py`: punto de entrada principal.
- `modules/`: módulos auxiliares del procesamiento.

## Requisitos
- Python 3.10+
- Instalar dependencias desde el entorno virtual.

## Uso
1. Activar el entorno virtual.
2. Ejecutar `python main.py`.
